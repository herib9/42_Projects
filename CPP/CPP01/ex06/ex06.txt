Como el sistema switch de C++ no acepta strings directamente, primero debemos convertir ese texto en un número.

	A. La búsqueda del índice:

    Si el usuario pone "WARNING", el bucle se detiene cuando i = 2.

    Si el usuario pone algo que no existe, i terminará valiendo 4.

	B. El switch con Cascada (Fall-through):

Aquí es donde ocurre la magia del filtro. Al no poner la palabra break entre los casos, el código "se cae" al siguiente nivel.

switch (i)
{
    case 0: // Si i es 0 (DEBUG)
        this->debug();
        // FALLTHROUGH		-> Salta al caso 1 sin preguntar
    case 1: // Si i es 1 (INFO)
        this->info();
        // FALLTHROUGH 		-> Salta al caso 2
    case 2: // Si i es 2 (WARNING)
        this->warning();
        // FALLTHROUGH 		-> Salta al caso 3
    case 3: // Si i es 3 (ERROR)
        this->error();
        break; 			// Único freno: aquí se detiene
    default:
        std::cout << "\nProbably complaining about insignificant problems" << std::endl;
}

📝 Resumen del comportamiento letra por letra:

    Si eliges WARNING (i = 2):
        El programa salta directamente al case 2.
        Ejecuta warning().
        Como no hay break, cae al case 3.
        Ejecuta error().
        Encuentra el break y termina.
        Resultado: Ves Warning y Error.

    Si eliges ERROR (i = 3):
        Salta al case 3.
        Ejecuta error() y se detiene por el break.
        Resultado: Solo ves Error.

    Si eliges algo inválido (i = 4):
        No coincide con ningún caso del 0 al 3.
        Salta al default.
        Resultado: Mensaje de "insignificant problems".
